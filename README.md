# Simple-Code-Editor
A responsive and real-time **Live Code Editor** for writing, editing, and previewing **HTML, CSS**, and **JavaScript** code directly in the browser. Built using **Ace Editor** for rich syntax highlighting and a seamless coding experience.

---

## Features

- **Syntax Highlighting** with Ace Editor for HTML, CSS, and JS
- **Real-Time Output** – see your changes as you type!
- **Predefined Code Snippets** – load default templates or starter code
- **Single-Page App** – no reloads, just code and preview
- **Editable Live Preview Panel**
- Easy to extend or integrate into your own apps or websites
